# ぱずぎり ダメージ検証ノート

[中文](README.md) · 日本語

『[刀剣乱舞ぱずぎり](https://touken-puzzle.com/)』の非公式なダメージ記録ツールと、現時点での個人的な考察です。実測値、そこから考えた仮説、未検証の点を分けて書いています。データが増えれば結論も変わる可能性があります。

> **用語について：**ゲーム内ヘルプでは敵を「ト餓鬼」、爆発する球を「刀剣ボム」、紫のゲージを「ブレイクゲージ」、ゲージを削り切った後の時間を「乱舞ぎりタイム」、素早くなぞった際の効果を「速斬ボーナス」と呼んでいます。「レベル2の緑」などの色による区別は、このノートで使う説明上の呼び方です。

最初に押さえたいのは三つです。**一回の攻撃で表示されたダメージは、何体に当たったかと一緒に見ること。通常攻撃、刀剣ボムのレベル違い、奥義を同じ倍率として扱わないこと。そして、乱舞ぎりタイム・強化効果・クリティカルをそれぞれ記録すること。**

## 「一撃」はどこからどこまで？

このノートでは、画面に表示された**一回の攻撃のダメージ**を一件として記録します。同じ色のト餓鬼を一筆書きでなぞる通常攻撃、刀剣ボム一個の爆発、攻撃系の奥義を、それぞれ別の一件として扱います。乱舞ぎりタイム中に何回も攻撃した場合、その合計は「乱舞ぎりタイム中の合計ダメージ」であり、ミッションの「一撃のダメージ」と同じではありません。

| 攻撃の種類 | 記録する際のポイント |
| --- | --- |
| ト餓鬼をなぞる通常攻撃 | 同じ色のト餓鬼を一筆書きでなぞります。**誰が攻撃したか**を記録します。刀剣男士が違えば、ダメージの差をそのまま乱舞ぎりタイムや強化効果の倍率とは見なせません。 |
| レベル2の緑、レベル3のピンク、レベル4の白の刀剣ボム | 刀剣ボムのレベル、当たったト餓鬼の数、ダメージを別々に記録します。観察上、ピンクはタップして起爆し、白は自動で爆発します。 |
| 攻撃系の奥義 | 発動した刀剣男士、実際に当たった敵の数、ダメージを記録します。奥義の効果はそれぞれ異なります。 |
| 画面全体に届く爆発 | 多くのト餓鬼に当たっても、一撃のダメージが必ず高くなるわけではありません。 |

「当たったト餓鬼の数」は、その攻撃が**実際に命中した数**です。画面上にいるト餓鬼の総数とは区別します。同じピンクの刀剣ボムでも、18体に当たった結果と25体に当たった結果を総ダメージだけで比較することはできません。

### ブレイクゲージと乱舞ぎりタイム

ボスにはHPのほかに紫色の**ブレイクゲージ**があります。ゲーム内ヘルプによると、攻撃・刀剣ボム・奥義でこのゲージを削り切ると**乱舞ぎりタイム**が発動します。刀剣ボムでゲージが大きく減った場面と、通常攻撃でHPにダメージを与えてもゲージが残った場面を確認しています。ただし、命中数や攻撃の種類も違っていたため、**刀剣ボム一体分のゲージ減少量までは確定していません**。

ツールの「乱舞中」は、その攻撃が乱舞ぎりタイム中に行われたことを示します。ブレイクゲージを削り切ることと時間の発動はつながっているため、**時間内／時間外の比を、そのまま独立した「乱舞倍率」とは呼べません**。どの状態がどれだけダメージを変えるかは、まだ切り分けられていません。

### 強化効果とクリティカル

乱藤四郎の奥義には味方の攻撃力を上げる効果がありますが、説明文から具体的な上昇率は分かりません。ツールの **Buff** は、強化効果を「なし／乱藤四郎の奥義／その他／未記録」に分けて残す欄です。「その他」を乱藤四郎の効果と同じグループには入れません。

ゲーム内ヘルプでは、**長く素早くト餓鬼をなぞると速斬ボーナスが付き、ダメージが増える**と説明されています。増加量は未検証です。現在のツールには速斬ボーナス専用の入力欄がないため、通常攻撃の記録同士を比べるときはこの条件にも注意が必要です。

クリティカルもダメージを変えます。絵馬にはクリティカル率や威力に関する効果がありますが、今回のデータだけで発生率や倍率を求めることはできません。発生したか判断できない場合は「未記録」にして、通常の比較から外します。

## なぜ「ト餓鬼一体あたりのダメージ」を計算するのか

まずは次の単純な指標で、命中数の違いを少し取り除きます。

```text
ト餓鬼一体あたりの平均ダメージ = その一撃で表示されたダメージ ÷ 命中したト餓鬼の数
```

例えばレベル3のピンクの刀剣ボムで21体に1093ダメージなら、`1093 ÷ 21 ≒ 52.0`。別の攻撃で19体に1481ダメージなら、`1481 ÷ 19 ≒ 77.9` です。

**これは比較のための平均値であり、ゲーム内部の計算式が分かったという意味ではありません。** ト餓鬼ごとの差、端数処理、上限などは未検証です。倍率を比較するときは、少なくとも攻撃の種類と刀剣ボムのレベルを揃え、可能なら攻撃した刀剣男士、部隊構成、強化効果、クリティカル、敵の条件も揃える必要があります。

## 現在の実測値

以下はすべて**一回の攻撃**の記録です。「一体あたり」は表示ダメージを命中数で割り、小数第一位まで示しています。

| 条件 | 命中数 | ダメージ | 一体あたり | この記録から言えること |
| --- | ---: | ---: | ---: | --- |
| レベル3ピンク、乱舞ぎりタイム外、Buffなし、クリティカルなし、部隊攻撃力575 | 21 | 1093 | 52.0 | この編成でのタイム外の基準点。 |
| レベル3ピンク、乱舞ぎりタイム中、Buffなし、クリティカルなし、部隊攻撃力586 | 19 | 1481 | 77.9 | 一体あたりは高いが、部隊攻撃力も変化している。 |
| レベル3ピンク、乱舞ぎりタイム中、乱藤四郎のBuffあり | 19 | 1781 | 93.7 | この一件だけではBuff単独の倍率は求められない。 |
| レベル3ピンク、乱舞ぎりタイム中、乱藤四郎のBuffあり | 25 | 2385 | 95.4 | 前の記録と一体あたりが近く、約94～95。 |
| レベル2緑、乱舞ぎりタイム中、乱藤四郎のBuffあり | 12 | 526 | 43.8 | レベル3ピンクとは別のグループで扱うべき。 |
| へし切長谷部の攻撃系奥義、乱舞ぎりタイム中、クリティカルなし | 24 | 2439 | 101.6 | 奥義の記録であり、刀剣ボムのデータとは分ける。 |
| レベル4白の全体爆発、Buffなし | 40 | 1475 | 36.9 | 広範囲に当たることと、一撃の高ダメージは別。 |

通常攻撃についても、長谷部 `9体／342`、乱 `7体／227`、歌仙 `13体／470`、長谷部 `4体／212` という初期記録があります。ただし、速斬ボーナスを含め、他の条件まで揃えた比較ではありません。歌仙が乱舞ぎりタイム中に23体へ1892ダメージを出した記録はクリティカルの可能性があり、通常の非クリティカル記録には含めません。

### 1.50倍と1.47倍の出し方

同じレベル3ピンクの刀剣ボムで、Buffなし・クリティカルなしの二件だけを比べます。

```text
乱舞ぎりタイム外：1093 ÷ 21 ≒ 52.0／体
乱舞ぎりタイム中：1481 ÷ 19 ≒ 77.9／体
元の比：(1481 ÷ 19) ÷ (1093 ÷ 21) ≒ 1.50倍
```

この二件の間に長谷部と歌仙がレベルアップし、部隊攻撃力は `575 → 586` に変わりました。**ダメージが部隊攻撃力に比例すると仮定した場合に限り**、次のような概算もできます。

```text
攻撃力で補正した比 ≒ 1.50 × 575 ÷ 586 ≒ 1.47倍
```

刀剣ボムのダメージが本当に部隊攻撃力に比例するかは未確認です。ブレイクゲージを削り切った後の状態と乱舞ぎりタイムの影響も切り分けられておらず、同条件のサンプルも少数です。**1.47倍を固定の「乱舞ぎりタイム倍率」として使うことはできません。**

### 部隊攻撃力が変わった理由

当時装備していた三枚の絵馬の攻撃力は `+17、+15、+9`、合計 `+41` でした。

```text
およそレベル20：長谷部167 + 乱147 + 歌仙189 + 絵馬41 = 部隊攻撃力544
レベル22：長谷部177 + 乱156 + 歌仙201 + 絵馬41 = 部隊攻撃力575
比較時：長谷部182 + 乱156 + 歌仙207 + 絵馬41 = 部隊攻撃力586
```

同じ三振りでも、育成途中なら攻撃力は変わります。ト餓鬼をなぞる通常攻撃では、部隊の合計だけでなく**実際に攻撃した刀剣男士**も記録する必要があります。すべての攻撃が部隊攻撃力を同じ割合で参照するという証拠は、まだありません。

## 一撃のダメージを伸ばしたいとき

以下は現在の観察から考えた試し方で、特定の数値を保証する攻略法ではありません。

1. ミッションが求めているのは「一撃」か「累計」かを確認します。乱舞ぎりタイム中の複数回の攻撃を足しても、一撃にはなりません。
2. 攻撃の種類と刀剣ボムのレベルを区別します。小さい刀剣ボムは盤面調整やブレイクゲージを減らす用途も考えられますが、一撃のダメージは命中数と各刀剣ボムの実測値で判断します。
3. ブレイクゲージを削り切って乱舞ぎりタイムが始まるタイミングを見ます。ピンクの刀剣ボムをタイム中まで残せれば、そこで起爆したときのダメージを測れます。白の刀剣ボムは自動で爆発し、Buffより先に発動したように見えた場面もあるため、発動順にも注意が必要です。
4. 乱藤四郎のBuff、クリティカル、攻撃力の変化を残します。複数の効果が重なるほど高ダメージを狙えますが、どの効果が何倍なのかは分かりにくくなります。
5. 「一撃6000／8000」を安定して出す手順は、現在の記録だけでは作れません。Buff、クリティカル、乱舞ぎりタイム、刀剣ボムのレベルをそれぞれ分けて測る必要があります。

刀剣ボムによるブレイクゲージの減少量、ゲージを削り切った後に残った刀剣ボムの扱い、速斬ボーナスの具体的な増加量、白の刀剣ボムの発動優先順位は、今後検証したい点です。ブレイクゲージには数値が表示されないため、画面上の一例から正確な減少量を決めることはできません。

## ツールの使い方

このリポジトリをダウンロードし、ブラウザーで [`index.html`](index.html) を開いてください。インストールは不要です。画面の表示は現在中国語です。入力欄は次の対応を見てください。

| 画面の表示 | このノートでの意味 |
| --- | --- |
| 攻击类型 | 攻撃の種類 |
| 出手刀剑男士 | 攻撃した刀剣男士 |
| 命中怪数 | 命中したト餓鬼の数 |
| 单次伤害 | 一回の攻撃で表示されたダメージ |
| 队伍攻击力 | 部隊の表示攻撃力 |
| 阶段 | 乱舞ぎりタイム中／タイム外 |
| Buff・暴击 | 強化効果・クリティカル |
| 导出 JSON・导入 JSON | 記録の書き出し・読み込み |

記録する手順は次の通りです。

1. 攻撃の種類、命中数、画面に表示された一回のダメージを入力します。
2. 通常攻撃では**攻撃した刀剣男士**を入力します。不明な古い記録は空欄のままにします。
3. 分かれば部隊攻撃力も入力し、乱舞ぎりタイム中／タイム外、Buffの種類、クリティカルの状態を選びます。判断できなければ「未記録」にします。
4. 表の記録は編集・削除できます。グラフは攻撃の種類と刀剣男士で絞り込めます。
5. 記録はブラウザー内に保存されます。定期的に **JSONを書き出してバックアップ**してください。JSONの読み込みは、現在の記録をファイルの内容に置き換えます。

初期データは十件です。このうち通常攻撃二件は攻撃した刀剣男士を当時記録していないため、未記録のままにしています。グラフに載せるのは、Buffが「なし」または「乱藤四郎の奥義」で、クリティカルが明確に「なし」の記録だけです。条件が不明な記録も表には残ります。

## まだ分からないこと

- 同じ攻撃・同じ命中数・同じ刀剣男士の場合、部隊攻撃力と本人の攻撃力はそれぞれどう計算に使われるのか。
- ブレイクゲージを削り切った後の状態と乱舞ぎりタイムのダメージへの影響を、どう切り分けられるか。
- 乱藤四郎の奥義の攻撃力上昇率と、絵馬・乱舞ぎりタイム・クリティカルとの関係。
- 刀剣ボムのレベルによって、一体あたりのブレイクゲージ減少量は違うのか。
- クリティカル、ト餓鬼ごとの差、端数処理によって「一体あたりの平均ダメージ」はどれくらい変わるのか。

これらの条件を一つずつ揃えて測ってから、内部の倍率式を考えたいと思います。今の数字は、**次に何を測るべきか決めるための手がかり**です。
