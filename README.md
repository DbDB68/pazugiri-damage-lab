# pazugiri 伤害实验台

记录《刀剑乱舞 结いの絵巻》的单次伤害，按攻击类型、乱舞窗口和 Buff 对照每怪伤害。

直接用浏览器打开 `index.html` 即可。记录保存在当前浏览器的本地存储里；可导出 JSON 备份，也可导入继续分析。

## 目前数据能说明什么

同为 3 级粉球、无 Buff、无暴击的两次记录：乱舞外 21 怪 1093 伤害，乱舞内 19 怪 1481 伤害。原始每怪伤害之比约 1.50；若暂时假设伤害和队伍面板攻击力成正比，按 575 与 586 校正后约 1.47。内外两次的队伍等级不同，且乱舞内同时可能包含 Break 效果，因此这不是单独的乱舞倍率。

图上每个点是一条实测记录，短横线是同组平均。不同出手刀剑男士的普通连线伤害不要直接当成同一倍率；可通过出手人筛选对照。历史记录若未记出手人，就标为「未记」。

## 数据口径

- 「命中怪数」和「单次伤害」是屏幕所显示的一击结果。
- 「队伍攻击力」是出战面板总攻击力，不等同于出手角色自己的攻击力。
- 「Buff」记录增伤来源：无、乱藤四郎奥义、其他、未记。其他 Buff 不与乱藤四郎奥义混作同一组。
- 未记 Buff、暴击状态不确定的记录保存在表格里，但不会用于基础倍率估算。
- 初始示例包含已讨论的八条炸弹/奥义实测和两条普通连线实测；两条普通连线的出手人当时未记。

这是实测整理和探索工具，计算结果是条件下的经验比值，并非已确认的游戏内部公式。
