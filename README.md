# pazugiri 伤害实验台

《[刀剣乱舞ぱずぎり](https://touken-puzzle.com/)》的非官方伤害记录工具，以及我目前对伤害机制的理解。游戏刚上线，下面有实测、有根据实测提出的猜想，也有尚未测清的地方；新数据可能推翻旧结论。

**第一次看可以先记住三件事：**屏幕上的一次攻击伤害要结合命中怪数看；普通连线、不同等级的炸弹和奥义不能混着算倍率；乱舞、Break、Buff、暴击可能同时出现，要分开记录。

## 先看懂一次攻击

这份记录把屏幕上**一次攻击显示的伤害数字**叫作「单次伤害」：普通连线出手一次、点爆一颗炸弹、或发动一次攻击型奥义，都各记一条。整段乱舞里可能连续发生多次攻击，把它们的伤害加起来是「乱舞期间总伤害」，不等于任务要求的「一击伤害」。

目前主要区分以下攻击方式：

| 方式 | 记录时要注意什么 |
| --- | --- |
| 普通连线／消除 | 记下**由哪位刀剑男士出手**。换人以后，不能直接把伤害差当成乱舞或 Buff 倍率。 |
| 2 级绿球、3 级粉球、4 级白球 | 分别记录球的等级、命中怪数和伤害；不能因为都是炸弹就合并比较。观察到 3 级粉球需主动点爆，4 级白球会自动爆炸。 |
| 奥义攻击 | 记录发动者、实际命中怪数和伤害；奥义的效果各不相同，不能一律拿普通攻击的每怪伤害套用。 |
| 全屏爆炸 | 4 级白球等全屏攻击能命中很多怪，但「命中多」不保证单次伤害一定高。具体伤害仍要实测。 |

这里的「命中怪数」指这次攻击**实际打到**多少怪，不是画面上总共有多少怪。比如同是粉球，炸到 18 怪与炸到 25 怪，两个总伤害本来就不宜直接比较。

### 韧性条、Break 和乱舞

Boss 除血量外，还有紫色韧性条。普通攻击和炸弹都能削韧；韧性条被打空会出现 Break。**削韧收益与直接伤害收益要分开看**：观察过炸弹很快清空韧性条，而普通连线造成伤害时韧性条仍在的情况，但当时命中怪数、攻击类型也不同，尚不足以确认「炸弹每命中一个怪削多少韧」。

本工具里的「乱舞内」只表示攻击发生在乱舞窗口中。实测里乱舞内往往还叠着 Break，所以**乱舞内／外的伤害比，是当时整套状态的比值，不是已拆出的纯乱舞倍率**。

### Buff 和暴击

乱藤四郎的奥义可以给队伍加攻击力；游戏文案没有给出具体百分比。工具里的 **Buff** 用来记录本次攻击有无增伤，以及目前已知的来源：无、乱藤四郎奥义、其他、未记。「其他」和「乱藤四郎奥义」不会在图上当成同一种 Buff 合并。

暴击也会明显改变数字。绘马可能影响暴击率或暴击威力，但**暴击率、暴击倍率和触发过程还没有从这批数据中反推出来**。看到疑似暴击但没有把握时，请选「未记」，不要硬塞进无暴击组。

## 为什么要算「每怪伤害」

现阶段先用一个很朴素的观察量：

```text
每怪伤害 = 这一次显示的伤害 ÷ 这一次命中的怪数
```

例如 3 级粉球炸到 21 怪、显示 1093 伤害，约是 `1093 ÷ 21 = 52.0 / 怪`。另一把炸到 19 怪、显示 1481 伤害，约是 `1481 ÷ 19 = 77.9 / 怪`。这样至少把「这次炸到更多怪」的影响从总数字里初步分开。

**这是比较用的平均数，不是已确认的游戏内部公式。** 它暂时假设这次命中的怪受到相近伤害；是否存在目标差异、取整、上限或别的特殊结算，还需要控制条件继续测。要比较倍率，至少先保持攻击类型和球等级相同，再尽量保持出手人、队伍配置、Buff、暴击和敌人条件相同。

## 目前有哪些实测

下面都记的是**一次攻击**，不是整段乱舞的总和。「每怪」由总伤害除以命中怪数得到，保留一位小数。

| 观察条件 | 命中 | 单次伤害 | 每怪 | 能说明什么 |
| --- | ---: | ---: | ---: | --- |
| 3 级粉球，乱舞外，无 Buff、无暴击，队攻 575 | 21 | 1093 | 52.0 | 当前配置下的一条窗口外基线。 |
| 3 级粉球，乱舞内，无 Buff、无暴击，队攻 586 | 19 | 1481 | 77.9 | 每怪高于上一条，但队伍攻击力也变了。 |
| 3 级粉球，乱舞内，有乱藤四郎 Buff | 19 | 1781 | 93.7 | Buff 窗口内的一条记录；不能只据此求 Buff 倍率。 |
| 3 级粉球，乱舞内，有乱藤四郎 Buff | 25 | 2385 | 95.4 | 与上一条每怪接近，约 94～95。 |
| 2 级绿球，乱舞内，有乱藤四郎 Buff | 12 | 526 | 43.8 | 与 3 级粉球相差明显；两种球应分开看。 |
| 压切长谷部攻击型奥义，乱舞内，未暴击 | 24 | 2439 | 101.6 | 这是奥义伤害，不应并入粉球组。 |
| 4 级白球全屏爆炸，无 Buff | 40 | 1475 | 36.9 | 命中范围大，并不自动成为高「一击」伤害。 |

早期还记过普通连线：长谷部 `9 怪 / 342`、乱 `7 怪 / 227`、歌仙 `13 怪 / 470`、长谷部 `4 怪 / 212`。它们能帮助理解普通连线也有「谁出手」「命中多少怪」的问题，但不是控制了所有条件的同组对照。另有歌仙在乱舞期间命中 23 怪、打出 1892 的记录，当时疑似暴击，故不能当作普通无暴击样本。

### 1.50× 和 1.47× 是怎么算的？

只拿上表**同为 3 级粉球、无 Buff、无暴击**的两次记录比较：

```text
乱舞外：1093 ÷ 21 ≈ 52.0 / 怪
乱舞内：1481 ÷ 19 ≈ 77.9 / 怪
原始每怪比值：(1481 ÷ 19) ÷ (1093 ÷ 21) ≈ 1.50
```

两次之间，长谷部和歌仙升级，队伍面板攻击力从 `575` 变成 `586`。**如果暂时假设伤害与队伍面板攻击力成正比**，可以再做一次粗略校正：

```text
攻击力校正后的内／外比值 ≈ 1.50 × 575 ÷ 586 ≈ 1.47
```

这个校正是假设，不代表已经证明炸弹伤害按队伍攻击力线性增长。并且「乱舞内」与 Break 叠在一起，样本目前只有两条，**1.47× 不能写成游戏的固定乱舞倍率**。

### 队伍攻击力为什么会变？

当时三位刀剑男士配的绘马攻击力分别是 `+17、+15、+9`，合计 `+41`：

```text
约 20 级：长谷部 167 + 乱 147 + 歌仙 189 + 绘马 41 = 队攻 544
22 级：长谷部 177 + 乱 156 + 歌仙 201 + 绘马 41 = 队攻 575
比较时：长谷部 182 + 乱 156 + 歌仙 207 + 绘马 41 = 队攻 586
```

这解释了为何不能只看「同一队」就当作攻击力完全没变。队攻是面板上显示的合计，**普通连线还要记下实际出手的刀剑男士**；目前没有证据证明所有攻击类型都以队攻按同一比例结算。

## 一击伤害高，实战上先看什么？

这是从现有观察出发的尝试顺序，**不是保证能打出特定数值的攻略**：

1. 先确认任务要的是「一击」还是累计伤害。乱舞里连续几次攻击的和，不能当作一击。
2. 区分攻击类型与球等级。小球可能适合清怪、削韧和铺场；要冲单次数字，优先观察能命中较多怪的高等级球，但不要只看覆盖范围。
3. 留意 Break 与乱舞时机。粉球如果能留到乱舞窗口再点爆，可以测试窗口内伤害；4 级白球会自动爆炸，曾观察到它先于 Buff 生效，触发顺序值得单独记录。
4. 把乱藤四郎 Buff、暴击和攻击力变化记清楚。几种因素叠在一起时，数字会变高，但也更难判断究竟是谁贡献了多少。
5. 如果目标是「一击 6000／8000」，目前的数据还不足以给出稳定配方；还需在同条件下测 Buff、暴击、Break 和不同等级球的独立影响。

炸弹削韧、Break 后剩余炸弹变成奖励、速斩奖励对伤害的影响，以及「4 级白球先爆」的触发优先级，都属于**观察或待验证假说**。尤其韧性条没有直接数值，不能把一次画面变化当成精确削韧公式。

## 使用实验台

下载仓库后，用浏览器打开 [`index.html`](index.html)，无需安装依赖。

1. 选攻击类型，填这次命中怪数、屏幕显示的单次伤害。
2. 普通连线请填实际**出手刀剑男士**；其他攻击若能确定发动者，也可以填。历史记录没写出手人就留空。
3. 尽量填队伍面板攻击力，并选乱舞内／外、Buff 来源与暴击状态。不确定就标「未记」。
4. 表格里可以编辑或删除记录；图表可按攻击类型和出手人筛选。
5. 浏览器会在本机保存记录。请定期**导出 JSON** 备份；导入 JSON 会用文件中的记录替换当前页面的数据。

工具初始带有十条已讨论的记录，其中两条普通连线当时没有记出手人，所以保留「未记」。图表只展示 Buff 为「无」或「乱藤四郎奥义」、且明确无暴击的记录；Buff「其他／未记」和暴击「有／未记」仍会留在表格里，等补充证据后再用于对照。

## 还没解开的题

- 同攻击类型、同怪数、同出手人下，队伍攻击力和个人攻击力分别如何进入结算？
- 乱舞窗口与 Break 各自增加多少伤害？两者是否相乘？
- 乱藤四郎奥义的攻击力加成是多少，与绘马、乱舞、暴击如何叠加？
- 各等级炸弹每命中一怪的削韧是否不同？全屏爆炸又如何计算？
- 暴击、目标差异、伤害取整会不会改变「每怪伤害」的稳定性？

能把这些条件逐项控制住，再谈完整倍率公式。现在的数字更适合用来**提出下一次该测什么**。
